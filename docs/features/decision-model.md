title: Decision Model
group: v1.7.0 Features
---

**Behavior:** An opt-in capability that answers small closed decision questions through a configurable backend, advisory and abstain-first. A caller sends a request with `state` text and named questions of three types: `choice` (pick one of 2 to 24 described options), `noul` (yes or no) and `score` (pick a level from an ordered scale and get a weighted score). Each answer is `ok` with a confidence, or an abstain with a reason: `capability-off`, `unreachable`, `model-missing`, `timeout`, `context-exceeded`, `invalid-output`, `too-many-options`, `low-confidence`, `egress-not-consented`, `invalid-config`, `invalid-request` or `order-inconsistent`. An abstain exits 0 so the caller falls back to its existing behavior; only a malformed request is a usage error. Answers below `decision_model.min_confidence` (default `0.9`) abstain, a question may carry its own floor, and a question with `order_check: true` is asked twice with the options reversed and abstains when the two picks differ. The state is sent to the backend unchanged and is never truncated. It is loopback-only unless `decision_model.allow_remote` is set in the user's own `$GSD_HOME/.gsd/defaults.json`; that key and `decision_model.api_key_env` (which must name a `*_API_KEY` variable, and whose key is only ever sent over https to a non-loopback host) are user scope only, so a value in a project or workstream `config.json` is ignored and reported by `decide --status` in `ignored_project_keys`. Calls within one invocation are strictly sequential, and one unreachable or timed-out result stops the remaining calls of that invocation. The state is untrusted text: an answer never gates a security or destructive action and is not used for planning, execution, verification verdicts or text generation, and its confidence is the model's preference over the offered options, not a calibrated probability. The `openai-letter` backend is live-tested against a local Tev1-4B served by LM Studio; the `jev` backend is contract-tested with fake HTTP only. An opt-in `decision_model.log_path` records one metadata line per answer (never the state or an API key), and nothing is written to `.gsd-trace.jsonl`.

**Commands:** `gsd-tools decide --request <path|->` | `gsd-tools decide --status [--probe]`.

**Config:** `decision_model.enabled` (master gate, default `false`), `decision_model.backend` (default `openai-letter`), `decision_model.base_url` (default `http://127.0.0.1:1234`), `decision_model.model` (default empty, which abstains `model-missing`), `decision_model.allow_remote` (default `false`), `decision_model.min_confidence` (default `0.9`), `decision_model.timeout_ms` (default `30000`), `decision_model.api_key_env` (default `OPENROUTER_API_KEY`, the name of an environment variable) and `decision_model.log_path` (default empty). See [Configuration Reference](CONFIGURATION.md#decision-model-settings).

**Backward compatibility:** Off by default. When `decision_model.enabled` is `false` every question abstains `capability-off`, no network call is made and nothing is written; a project that never enables it is completely unaffected.
